# FURNEST 🛋️

A full-stack web application designed for pet owners, caretakers, and booking-related management.

---

## 🚀 Tech Stack

### **Frontend**
* **React.js & Vite:** Fast frontend development and building.
* **Tailwind CSS:** Modern and responsive utility-first styling.

### **Backend & Database**
* **Node.js & Express.js:** RESTful API server implementation.
* **MongoDB & Mongoose:** NoSQL data storage and schemas.

### **Security & Authentication**
* **JWT (JSON Web Tokens):** Secure session handling and protected endpoints.
* **bcrypt:** Password hashing and encryption.
