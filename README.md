# FURNEST 🛋️

A full-stack web application built to provide a modern, seamless experience for furniture browsing and booking/management.

---

## 🚀 Tech Stack

* **Frontend:** React.js / Client-side framework
* **Backend:** Node.js, Express.js
* **Database & Services:** MongoDB / REST APIs / Socket.io
